# Cybersecurity Awareness Bot

## Description

A GUI-based chatbot application developed in C# Windows Forms that educates users about cybersecurity awareness.

## Features

* GUI chatbot
* Voice greeting
* ASCII art
* Keyword recognition
* Sentiment detection
* Memory recall
* Random responses
* GitHub Actions CI

## Technologies Used

* C#
* Windows Forms
* GitHub Actions

## How to Run

1. Open solution in Visual Studio
2. Run the application
3. Interact with the chatbot
